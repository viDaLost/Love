# Вселенная в твоих глазах

Сайт: **https://vidalost.github.io/Love/**

Полноэкранная символьная история: отражение галактики в оливковом глазу → полёт через зрачок → Млечный Путь сверху → его ядро становится красной кардиограммой → первый удар рождает сосуды и сердце → «Я тебя люблю» → три пульсирующих пиксельных сердца → звёзды возвращаются в блик на глазу.

Портрет не используется. Фотографии не включены в проект. Форма век, бровь и оливково-золотистая радужка основаны на фотографических референсах.

## Одна непрерывная композиция

Внутри радужки видно маленькое спиральное отражение с тёплым ядром и холодными рукавами. Галактика остаётся диском при любой ориентации экрана; фоновые звёзды, ближние светила и прозрачная пыль движутся с разной скоростью. Текстуры и звёздные скопления кэшируются при изменении размера.

При выходе из космоса ядро вытягивается в световую линию, а звёзды из рукавов собираются вдоль красной кардиограммы. Первая пульсовая волна запускает появление сосудов и анатомического сердца. Ритм — 72 удара в минуту.

Сердце сокращается неравномерно: нижняя часть слегка скручивается и сжимается отдельно. SVG отрисовывается через неглубокую сетку полос. Корни входящих сосудов используют ту же деформацию и поворот, поэтому соединения остаются на месте. Световые волны приходят к сердцу в такт его двойному удару; мягкий движущийся блик подчёркивает объём.

Перед признанием есть короткая звуковая пауза. Каждое слово возникает из мягкой вспышки и символьных искр. После появления всех трёх пиксельных сердец они пульсируют вместе. В финале буквы и сердца становятся звёздами; частицы сходятся в рассчитанную точку блика на глазу, камера отдаляется, и быстрое моргание переходит через границу цикла. Последний кадр совпадает с первым.

## Звук и управление

Кнопка «Включи звук» включает сопровождение и меняет подпись на «Выключи звук». Крестик скрывает весь блок до перезагрузки. После скрытия звук по-прежнему переключается касанием анимации или клавишей M. Enter и пробел на кнопках работают как обычное управление кнопками и не меняют ход анимации.

Web Audio создаётся только после действия пользователя. Используются мягкий пролёт, стереофонические звёздные ноты, меняющаяся гармония, спокойная мелодия, двойной стук сердца и арпеджио слов. Гармония раскрывается на «люблю». Позиции звёздных звуков согласованы с положением вспышек; при поддержке браузером используются StereoPanner и реверберация. Перед первым словом приглушаются и основной сигнал, и хвост реверберации.

Звук и изображение используют одни временные отметки. При скрытии вкладки и паузе AudioContext приостанавливается; при продолжении возобновляется. Синтез ограничен мягкой компрессией. Аудиофайлов, сторонних шрифтов, внешних зависимостей и API-ключей нет.

## Тайминг

Один цикл — 66 секунд.

| Время | Сцена |
| --- | --- |
| 0–6,5 с | Оливковый глаз, отражение галактики, быстрое моргание |
| 6,5–11,5 с | Приближение через зрачок |
| 11,5–20 с | Млечный Путь сверху, глубина звёзд и пыли |
| 20–23 с | Ядро вытягивается в красную кардиограмму |
| 23–28 с | Красный сердечный ритм |
| 28–32 с | Первый удар запускает волну, сосуды и сердце |
| 32–39,2 с | Объёмное сокращение сердца и пульс сосудов |
| 39,2–40,4 с | Замирание перед признанием |
| 40,4 / 43 / 45,6 с | «Я», «тебя», «люблю» |
| 48,2 / 49,6 / 51 с | Три пиксельных сердца, общий пульс |
| 54–56,3 с | Буквы и сердца рассыпаются на звёзды |
| 56,3–60,5 с | Звёзды собираются в блик, проявляется глаз |
| 59,3–64,6 с | Камера отдаляется от глаза |
| 65,9 с → следующий цикл | Быстрое моргание замыкает повтор |

## Публикация и разработка

GitHub Pages автоматически публикует main через .github/workflows/pages.yml. Источник — GitHub Actions. Это статические HTML/CSS/JavaScript, пути относительные. Все необходимые файлы входят в assets/.

Для локального сервера и проверок нужен Node.js 22+:

~~~sh
npm start
npm run check
npm test
~~~

Открой http://localhost:8080. Пробел — пауза, Enter — повтор, M — звук. При системном уменьшении движения показываются неподвижные слова и три сердца. Скрытая вкладка не продолжает воспроизведение. Символьная сетка адаптируется к производительности; на границе цикла она не меняется, чтобы повтор оставался плавным.

- assets/model.js — тайминг, отражение, глаз, моргание, камера возврата и общий ритм.
- assets/galaxy.js — спиральный диск, пыль и звёздные слои.
- assets/vessels.js — деформация сердца, соединения и пульс сосудов.
- assets/sound.js — пространственный синтез, мелодия, гармония и синхронизация.
- assets/animation.js — символьная отрисовка, переходы, слова и превращение финала в звёзды.
- tests/animation.test.mjs — проверки сцены, глаза, возврата, деформации сосудов, ритма и партитуры.
