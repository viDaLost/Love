# Вселенная в твоих глазах

Сайт: **https://vidalost.github.io/Love/**

Полноэкранная символьная анимация со скрываемой кнопкой звука: один глаз → полёт через зрачок → движущийся Млечный Путь → красная кардиограмма → анатомическое сердце с сосудами → «Я тебя люблю» → три пиксельных сердца → плавный повтор. Портрет и код его отрисовки удалены.

## Глаз и космос

В основе — первоначальная геометрия глаза. По фотографическим референсам изменены миндалевидные веки, мягкий изгиб брови, приподнятый внешний угол и оливково-золотистый цвет радужки. Верхнее веко быстро закрывает глаз и немного медленнее открывается. Фотографии не загружаются и не включены в проект.

Млечный Путь показан сверху: круглый спиральный диск с тёплым ярким ядром, центральной перемычкой, двумя основными и двумя более слабыми рукавами, голубыми звёздными скоплениями и пылевыми прожилками. Геометрия учитывает пропорции символьных ячеек и сохраняет круглый вид на телефоне и широком экране. Диск медленно вращается и приближается; отдельные звёзды мерцают и движутся на разной глубине. Текстура кэшируется при изменении размера. Цвета всей анимации слегка усилены.

## Сердце и сосуды

Анатомическое сердце увеличено; сосудистая сеть автоматически следует за его новым размером. Сосудистая сеть растёт внутрь со всех четырёх сторон экрана и подходит к координатам открытых сосудов в SVG сердца. Геометрия соединений обновляется по тому же масштабу сердца на каждом кадре. Световые волны идут к сердцу и достигают корней сосудов в такт двойному удару, 72 уд/мин. Кардиограмма красная.

## Звук

Кнопка «Включи звук» внизу экрана включает сопровождение и меняет подпись на «Выключи звук». Крестик рядом скрывает весь блок до перезагрузки страницы. Звук также переключается касанием самой анимации или клавишей M, в том числе после скрытия кнопки. Кнопки доступны с клавиатуры; их нажатие Enter или пробелом не перезапускает и не приостанавливает анимацию. Звуковой движок создаётся только после действия пользователя: браузеры телефонов ограничивают автоматическое воспроизведение.

Web Audio синтезирует мягкий воздушный переход, спокойный гармонический фон в космосе, звёздные колокольчики, двойной стук сердца и арпеджио при появлении слов. Звук сердцебиения использует те же временные отметки, что и изображение. Предусмотрены реверберация, мягкая компрессия и невысокая громкость. Внешних аудиофайлов, загрузок и зависимостей нет. При скрытии вкладки или паузе звук останавливается вместе с анимацией.

## Тайминг

Один цикл — 58 секунд.

| Время | Сцена |
| --- | --- |
| 0–6,5 с | Глаз, бровь, радужка и быстрое моргание |
| 6,5–11,5 с | Приближение через зрачок |
| 11,5–20 с | Млечный Путь сверху: вращение спиральных рукавов и движение звёзд |
| 20–23 с | Звёзды собираются в красную кардиограмму |
| 23–28 с | Красный сердечный ритм |
| 28–32 с | Сердце появляется, сосуды сходятся от краёв |
| 32–40 с | Сердце и сосуды пульсируют вместе |
| 40 / 42,5 / 45 с | Слова «Я», «тебя», «люблю» из искр |
| 47,4 / 48,7 / 50 с | Три пиксельных сердца |
| 53,5–58 с | Возвращение к глазу и бесшовный повтор |

## Публикация и разработка

GitHub Pages автоматически публикует main через .github/workflows/pages.yml. Источник — GitHub Actions. Это статические HTML/CSS/JavaScript, все ссылки относительные. Зависимости, API-ключи и команда сборки не требуются.

Для локальных проверок нужен Node.js 22+:

~~~sh
npm start
npm run check
npm test
~~~

Открой http://localhost:8080. Пробел — пауза, Enter — повтор, M — звук; кнопка звука скрывается крестиком. При системном уменьшении движения показываются неподвижные слова и три сердца. Поддерживаются экранный диктор и разные ориентации телефона.

- assets/model.js — тайминг, геометрия глаза и ритм.
- assets/galaxy.js — многослойное галактическое небо.
- assets/vessels.js — размер сердца, соединения и пульс сосудов.
- assets/sound.js — синтез и синхронизация звука.
- assets/animation.js — символьная отрисовка, переходы, сердце и слова.
- tests/animation.test.mjs — проверки глаза, приближения, космоса, соединений, пульса, звука и повторения.
