# Вселенная в твоих глазах

Полноэкранная символьная анимация без меню и панелей.
Сайт: **https://vidalost.github.io/Love/**

Девушка в полуобороте поворачивается к зрителю, смотрит в камеру и мягко улыбается. Камера приближается к болотно-зелёному глазу и проходит через зрачок в Млечный Путь. Звёзды переходят в кардиограмму, затем появляется пульсирующее анатомическое сердце. «Я», «тебя», «люблю» возникают по одному из искр и маленьких сердечек; под словами последовательно загораются три пиксельных сердца. Финал плавно возвращает исходный портрет.

## Анимация

Цикл длится 61 секунду.

| Время | Сцена |
| --- | --- |
| 0–3,3 с | Полуоборот, плавный поворот головы, взгляд на зрителя |
| 3,15–6,2 с | Мягкая улыбка, быстрое естественное моргание |
| 6,2–9,5 с | Приближение к левому глазу |
| 9,5–14,5 с | Полёт через зрачок без растворения лица |
| 14,5–21 с | Полоса Млечного Пути с пылевыми прожилками и вспышками маленьких звёзд |
| 21–24 с | Звёзды собираются в кардиограмму |
| 24–29 с | Зелёная кардиограмма, 72 уд/мин |
| 29–33 с | Переход в анатомическое сердце |
| 33–42 с | Сердце с сосудами и двойным пульсом |
| 42 / 44,5 / 47 с | «Я», «тебя», «люблю»: символьные искры и сердечки |
| 49,4 / 50,7 / 52 с | Три пиксельных сердца под словами |
| 55,5–61 с | Возвращение к начальной позе; бесшовный повтор |

Портрет нарисован кодом по фотографическим референсам: мягкий овал лица, центральный пробор, длинные каштановые волосы, веснушки, светлая кожа, полные губы и оливково-зелёные глаза. Это художественная символьная интерпретация. Исходные фотографии не включены в проект. Поворот использует проекцию точек лица с разной глубиной; взгляд, веки, щёки и губы анимируются вместе.

Сохранены символьная отрисовка, кардиограмма и детальное векторное анатомическое сердце первого сайта. Все сцены рисуются символами, финальные три сердца — отдельными чёткими пикселями.

## Публикация

Статические HTML, CSS и JavaScript. Зависимости, API-ключи и команда сборки не требуются. Все ресурсы локальные; пути относительные и поддерживают /Love/.

GitHub Pages публикует main автоматически через .github/workflows/pages.yml. Источник в Settings → Pages — GitHub Actions. Workflow размещает только index.html, .nojekyll и assets/. Проверки синтаксиса и тесты запускаются отдельным workflow check.yml.

## Телефон и доступность

Адаптация к портретным и альбомным экранам; 30 кадров/с с автоматическим снижением символьной сетки при замедлении. Во время скрытия вкладки анимация приостанавливается. При системном «Уменьшении движения» показываются неподвижные слова и три сердца. Экранный диктор получает описание и слова по мере появления. Пробел — пауза, Enter — повтор; видимых элементов управления нет. Звук и разрешения устройства не требуются.

## Локальная разработка

Для необязательного локального сервера и проверок нужен Node.js 22+:

~~~sh
npm start
npm run check
npm test
~~~

Открой http://localhost:8080. Для модулей JavaScript нужен HTTP-сервер, открытие через file:// не поддерживается.

- assets/model.js — тайминг, моргание, математическая модель ритма.
- assets/portrait.js — черты лица, проекция поворота, улыбка и камера.
- assets/animation.js — символьный атлас, Млечный Путь, переходы и финал.
- assets/style.css — полноэкранное полотно.
- tests/animation.test.mjs — порядок сцен, поворот, взгляд, улыбка, моргание, проход через зрачок на разных экранах, возврат и сердцебиение.
