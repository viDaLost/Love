# Вселенная в твоих глазах

Полноэкранная символьная анимация. Никаких меню, кнопок, подписей или панелей поверх сцены.

Женственный глаз с болотной радужкой и короткими естественными морганиями → приближение всей сцены через зрачок → вселенная с маленькими взрывающимися звёздами → сердечный ритм → пульсирующее анатомическое сердце → «Я», «тебя», «люблю». Каждое слово возникает из символов с разлетающимися искрами и маленькими сердечками. В финале слова остаются вместе.

## Публикация на GitHub Pages

1. Открой [Settings → Pages](https://github.com/viDaLost/Love/settings/pages).
2. В **Build and deployment → Source** выбери **GitHub Actions**.
3. Публикация выполняется автоматически при обновлении **main**. Для ручного запуска открой **Actions → Publish GitHub Pages → Run workflow**.

Процесс публикации находится в `.github/workflows/pages.yml` и загружает только `index.html`, `.nojekyll` и `assets/`.

После успешной публикации GitHub покажет адрес сайта:
**https://vidalost.github.io/Love/**

Это обычные HTML, CSS и JavaScript. Команда сборки, npm install, сервер, API-ключи и внешние сервисы не требуются. Файл .nojekyll отключает обработку Jekyll. Все ссылки на файлы относительные, поэтому путь /Love/ поддерживается.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Анимация

Один цикл длится 42 секунды и повторяется автоматически.

| Время | Сцена |
| --- | --- |
| 0–7,2 с | Объёмный глаз, веки, ресницы, волокна радужки, блики и короткие моргания |
| 7,2–11,8 с | Вход камеры в зрачок; весь глаз приближается |
| 11,8–17,4 с | Звёздное пространство и небольшие вспышки |
| 17,4–22,4 с | Звёзды собираются в кардиограмму, затем идёт сердечный ритм |
| 22,4–25,2 с | Символы кардиограммы собираются в анатомическое сердце |
| 25,2–30,6 с | Сокращения сердца с двойным ударом, 72 уд/мин |
| 30,6 / 33,1 / 35,6 с | По одному появляются «Я», «тебя», «люблю» |
| 40,4–42 с | Плавное затемнение перед новым циклом |

Изображение процедурное: глаз и сердце строятся из геометрии, теней и текстовых символов. Готовые фотографии, видео и сторонние шрифты не загружаются. Все видимые детали, включая кардиограмму и финальные слова, отрисованы символами.

## Телефон и доступность

- Адаптация к портретной и альбомной ориентации, в том числе iPhone.
- 30 кадров/с, ограничение плотности пикселей, атлас символов и кэш геометрии сердца.
- Анимация приостанавливается, когда вкладка скрыта, и продолжается с того же места.
- При системной настройке «Уменьшение движения» показывается неподвижное признание.
- Для клавиатуры: пробел — пауза/продолжение, Enter — повтор с начала. Видимого интерфейса нет.
- Для экранного диктора есть описание и последовательное озвучивание слов.
- Звук и разрешения устройства не требуются.

## Локальный запуск и проверки

Нужен Node.js 22+ только для локального сервера и проверок:

~~~sh
npm start
~~~

Открой http://localhost:8080. Не открывай index.html через file://: браузер блокирует импорты JavaScript-модулей на локальном файловом протоколе.

~~~sh
npm run check
npm test
~~~

Проверки охватывают тайминг, моргания, геометрию глаза и сердца, масштабирование, финальные слова, жизненный цикл и вызовы отрисовки на мобильных и широких экранах. Автоматическая проверка выполняется также в GitHub Actions.

## Файлы

- index.html — единственный экран.
- assets/style.css — полноэкранное полотно.
- assets/model.js — геометрия и тайминг.
- assets/animation.js — символьная отрисовка и переходы.
- scripts/ — необязательный локальный сервер и проверка синтаксиса.
- tests/ — автоматические проверки.
